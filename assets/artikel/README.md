Folder ini disiapkan untuk foto artikel lokal Bradwear.

Aturan penggunaan saat ini:
- Jika foto final artikel belum tersedia di folder ini, website memakai fallback foto online gratis yang didefinisikan di `lib/siteConfig.ts`.
- Saat foto lokal sudah siap, ganti URL fallback pada data artikel dengan file dari folder `assets/artikel/`.
- Simpan nama file yang deskriptif agar mudah dipetakan per slug artikel.
